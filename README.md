FitLog — Workout Library & Daily Plan
FitLog is a workout library and daily fitness planner built with Next.js. Browse exercises, view workout details, save workouts for later, and organize up to five workouts in your daily plan.
Technologies Used
- Next.js — React framework and application routing
- React — component-based user interface
- JavaScript (JSX) — application logic and UI
- Tailwind CSS v4 — styling setup
- Lucide React — icons
- Sonner — toast notifications
- Browser Local Storage — saves the plan, saved workouts, and completion status on the device
5 Key Features
1. Workout Library — browse available workouts and their key information.
2. Workout Details — open a workout page to see its information and instructions.
3. My Plan — add workouts to a daily plan, with a limit of five workouts.
4. Mark as Done — mark a planned workout as completed using the check-icon button; a success toast appears and the card shows “DONE FOR TODAY”.
5. Save and Remove Workouts — save workouts for later, or remove a workout from My Plan or Saved; a toast confirms the removal.
